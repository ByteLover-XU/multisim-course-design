# 数字电路课程设计：8 位多寄存器 CPU 仿真与 4 位 ACC＋ALU 实物系统

本仓库用于记录数字电路课程设计的设计、仿真、PCB 制作、实物调试与总结过程。项目由两部分组成：

1. **仿真部分**：在 Multisim 中实现一个 8 位多寄存器、自定义指令集的简易 CPU；
2. **实物部分**：在原有 4 位 ALU 基础上加入 ACC 累加寄存器与反馈通路，完成 4 位 ACC＋ALU 电路的原理图、PCB、焊接和调试。

> 仓库名称保留为 `multisim-course-design`，项目内容已由早期的 Multisim 电路协作逐步扩展为完整课程设计记录。

## 一、项目目标

本课程设计旨在将组合逻辑、时序逻辑、存储器与控制逻辑结合起来，完成从模块仿真到实物电路实现的完整数字系统设计流程。

主要目标包括：

- 完成 8 位多寄存器 CPU 的模块划分与 Multisim 仿真；
- 设计自定义指令集及相应控制逻辑；
- 实现 PC、ROM、寄存器堆、ALU、RAM 和控制单元之间的数据传递；
- 通过测试程序验证 CPU 的指令执行和跳转功能；
- 在 4 位 ALU 基础上增加 ACC，实现运算结果保存与反馈运算；
- 完成元器件选型、原理图绘制、PCB 设计、焊接和实物调试。

## 二、系统组成

### 1. CPU 仿真系统

CPU 仿真部分主要由以下模块组成：

- 程序计数器 PC
- 指令存储器 ROM
- 通用寄存器组
- 算术逻辑单元 ALU
- 控制单元
- 数据存储器 RAM
- 状态标志与跳转逻辑
- LED 输出模块

基本数据通路如下：

```text
PC → ROM → 指令译码 → 寄存器组 → ALU → RAM / 寄存器写回
 ↑                              ↓
 └────────── 跳转控制与状态标志 ──────────┘
```

### 2. ACC＋ALU 实物系统

实物部分由 4 位 ALU、ACC 累加寄存器、数据选择、时钟控制和 LED 显示等模块组成。

```text
外部输入 ──┐
           ├──→ ALU ──→ ACC ──→ LED 显示
ACC 反馈 ──┘          │
                      └── 时钟更新
```

ACC 在有效时钟沿到来时保存 ALU 输出，并将保存的数据反馈至 ALU，从而支持连续累加和多步运算。

## 三、CPU 仿真部分

### 1. 数据与指令

- 数据宽度：8 位
- 指令宽度：16 位
- 指令存储：ROM
- 数据存储：16×8 RAM
- 寄存器寻址：多寄存器结构

### 2. 主要指令

项目自定义了数据传送、算术运算、存储与跳转类指令，包括：

| 指令 | 功能 |
|---|---|
| `LI` | 将立即数写入寄存器 |
| `SUB` | 两个操作数相减 |
| `ST` | 将数据写入 RAM 或输出端口 |
| `JMP` | 无条件跳转 |
| `BZ` | 结果为零时跳转 |
| `BB` | 出现借位时跳转 |

跳转控制逻辑可概括为：

```text
JumpEnable = isJMP
           OR (isBZ AND Zero)
           OR (isBB AND Borrow)
```

### 3. 功能验证

CPU 使用求最大公约数程序进行综合验证。测试目标为：

```text
gcd(12, 8) = 4
```

程序通过 `LI`、`SUB`、`BZ`、`BB`、`JMP` 和 `ST` 等指令完成循环、比较、减法与结果输出，并通过 LED 输出端观察最终结果。

## 四、ACC＋ALU 实物部分

### 1. 主要功能

- 完成 4 位算术与逻辑运算；
- 在时钟信号作用下保存 ALU 运算结果；
- 将 ACC 输出反馈至 ALU 输入端；
- 通过选择电路切换外部数据与反馈数据；
- 通过 LED 显示输入、输出和状态；
- 支持手动时钟控制与实物调试。

### 2. 主要器件

| 器件 | 主要作用 |
|---|---|
| 74LS175 | 保存 ACC 数据 |
| 74LS157 | 选择外部输入或 ACC 反馈数据 |
| 74LS14 | 按键消抖与信号整形 |
| 74LS07 | 信号缓冲与驱动 |
| 74LS 系列逻辑门 | 运算控制、状态判断与辅助逻辑 |
| LED 与限流电阻 | 数据和状态显示 |
| 轻触按键 | 手动产生时钟控制信号 |

> 具体型号和数量以仓库中的 BOM 与采购清单为准。

### 3. PCB 设计流程

```text
Multisim 功能验证
        ↓
嘉立创 EDA 原理图绘制
        ↓
器件符号与封装检查
        ↓
PCB 布局、布线与铺铜
        ↓
DRC 检查
        ↓
Gerber 导出与 PCB 打样
        ↓
焊接、上电测试与故障排查
```

## 七、调试记录

项目过程中遇到的主要问题包括：

1. Multisim 仿真器件与实际可采购芯片型号不完全一致；
2. 嘉立创 EDA 元件库中缺少部分 74LS 系列器件，需要申请或自建器件；
3. 自建符号与封装时，需要严格核对引脚编号、引脚间距和封装方向；
4. 机械按键直接作为时钟输入时会产生抖动，需要使用消抖和整形电路；
5. 原理图修改后，必须同步更新 PCB，避免网络表与实际连接不一致；
6. 选择端、使能端和未使用输入端不能随意悬空；
7. PCB 初版布局空间不足，需要重新规划芯片、接口和走线位置；
8. Multisim 工程文件为二进制文件，多人协作时难以自动合并冲突。

更详细的问题、分析过程和解决方案可在 `docs/` 目录中继续补充。
