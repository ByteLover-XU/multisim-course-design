# 数字电路课程设计：8 位多寄存器 CPU 仿真与 4 位 ACC＋ALU 实物系统

本仓库用于记录数字电路课程设计的方案设计、Multisim 仿真、PCB 制作、实物调试与总结过程。项目由两个相互关联但实现范围不同的部分组成：

1. **仿真部分**：在 Multisim 中实现一个 8 位多寄存器、自定义指令集的简化 CPU；
2. **实物部分**：在原有 4 位 ALU 基础上加入 ACC 累加寄存器、反馈通路与时钟控制，完成 4 位 ACC＋ALU 系统。

> 最终方案说明：CPU 仿真中不设置数据 RAM，运算数据保存在通用寄存器中；程序结果通过 `ST` 指令写入 LED 输出寄存器。

## 一、项目目标

本课程设计旨在将组合逻辑、时序逻辑、存储器和控制逻辑结合起来，完成从模块仿真到实物电路实现的数字系统设计流程。

主要目标包括：

- 完成 8 位多寄存器 CPU 的模块划分与 Multisim 仿真；
- 设计 16 位自定义指令集及相应控制逻辑；
- 实现 PC、ROM、寄存器组、ALU、状态标志和跳转控制之间的数据传递；
- 使用寄存器保存运算数据，不设置数据 RAM；
- 通过 GCD 测试程序验证循环、比较、减法和跳转功能；
- 使用 `ST` 指令把最终结果写入 LED 输出寄存器；
- 在 4 位 ALU 基础上增加 ACC，实现结果保存与反馈运算；
- 完成器件选型、原理图、PCB、焊接和实物调试。

## 二、系统组成

### 1. CPU 仿真系统

CPU 仿真部分由以下模块组成：

- 4 位程序计数器 PC；
- 16×16 bit 指令 ROM；
- 指令译码与控制单元；
- 8 个 8 位通用寄存器 R0～R7；
- 8 位 ALU；
- Zero 与 Borrow 状态标志；
- 跳转判断与 PC 选择逻辑；
- LED 输出寄存器。

最终数据通路：

```text
                 ┌──────────── 跳转地址 ────────────┐
                 │                                  ▼
PC → ROM → 指令译码 → 寄存器组 → ALU → 寄存器写回 → PC选择
                              │       │
                              │       └→ Zero / Borrow
                              └────────→ LED_OUT（ST）
```

CPU 中不设置数据 RAM。GCD 程序的中间数据全部保存在通用寄存器中。

### 2. ACC＋ALU 实物系统

实物部分由 4 位 ALU、ACC 累加寄存器、数据选择、手动时钟、消抖整形和 LED 显示模块组成。

```text
外部输入 ──┐
           ├──→ 数据选择 ──→ 4位 ALU ──→ ACC ──→ LED
ACC 反馈 ──┘                         │
                                    └──反馈到后续运算
```

ALU 先完成组合逻辑运算；有效时钟沿到来后，ACC 保存 ALU 输出，并把保存结果反馈到后续运算通路，从而支持连续累加和多步运算。

## 三、CPU 仿真规格

| 项目 | 最终规格 |
|---|---|
| 数据宽度 | 8 bit |
| 指令宽度 | 16 bit |
| 通用寄存器 | R0～R7，共 8 个 |
| R0 | 固定为 0 |
| PC 宽度 | 4 bit |
| 指令 ROM | 16×16 bit |
| 数据 RAM | 不使用 |
| ALU 运算 | ADD、SUB、AND、OR |
| 状态标志 | Zero、Borrow |
| 跳转指令 | JMP、BZ、BB |
| 输出方式 | `ST` 写入 LED 输出寄存器 |
| 验证程序 | 辗转相减法求最大公约数 |

## 四、自定义指令集

| opcode | 指令 | 功能 |
|---|---|---|
| `0000` | `NOP` | 空操作 |
| `0001` | `LI rd, imm8` | 将立即数写入寄存器 |
| `0010` | 保留 | 当前方案不使用 |
| `0011` | `ST rs` | 将寄存器数据写入 LED 输出寄存器 |
| `0100` | `ADD rd, rs1, rs2` | 两个寄存器相加 |
| `0101` | `SUB rd, rs1, rs2` | 两个寄存器相减并更新标志 |
| `0110` | `AND rd, rs1, rs2` | 按位与 |
| `0111` | `OR rd, rs1, rs2` | 按位或 |
| `1000` | `JMP addr` | 无条件跳转 |
| `1001` | `BZ addr` | Zero 为 1 时跳转 |
| `1010` | `BB addr` | Borrow 为 1 时跳转 |

跳转判断逻辑：

```text
JumpEnable = isJMP
             OR (isBZ AND Zero)
             OR (isBB AND Borrow)
```

## 五、GCD 功能验证

CPU 使用辗转相减法验证完整数据通路，示例目标为：

```text
gcd(12, 8) = 4
```

基本流程：

```text
R1 ← 12
R2 ← 8

循环：
    R3 ← R1 - R2
    若 R3 = 0，结束
    若 R1 < R2，则 R2 ← R2 - R1
    否则 R1 ← R3
    返回循环

结束：
    ST R1
```

最终结果通过 LED 输出寄存器显示。

## 六、ACC＋ALU 实物系统

### 1. 主要功能

- 完成 4 位算术与逻辑运算；
- 在有效时钟沿保存 ALU 结果；
- 将 ACC 输出反馈到 ALU 输入通路；
- 在外部输入和 ACC 反馈之间进行选择；
- 使用 LED 显示输入、ALU 输出、ACC 输出和状态；
- 使用轻触按键产生经过消抖与整形的手动时钟；
- 支持复位、单步运算和连续多步运算验证。

### 2. 主要器件

| 器件 | 主要作用 |
|---|---|
| 74LS175 | 4 位 ACC 数据保存 |
| 74LS157 | 外部输入与 ACC 反馈选择 |
| 74LS14 | 按键消抖与信号整形 |
| 74LS07 | 信号缓冲与 LED 驱动 |
| 74LS 系列逻辑器件 | ALU 运算、控制和状态判断 |
| LED 与限流电阻 | 数据及状态显示 |
| 轻触按键 | 手动时钟输入 |

> 具体型号、数量和封装以最终 BOM 与 PCB 工程为准。

### 3. 工作过程

```text
1. 设置外部输入和运算选择；
2. ALU 产生组合逻辑结果；
3. 按下时钟按键；
4. 消抖与整形电路产生有效时钟沿；
5. ACC 保存 ALU 输出；
6. ACC 输出反馈到下一次运算。
```

## 九、调试记录

项目过程中遇到的主要问题包括：

1. Multisim 仿真器件与实际可采购芯片型号不完全一致；
2. 嘉立创 EDA 元件库中缺少部分 74LS 系列器件，需要申请或自建器件；
3. 自建符号与封装时，需要严格核对引脚编号、间距和封装方向；
4. 机械按键直接作为时钟输入会产生抖动，需要消抖和整形；
5. 原理图修改后必须同步更新 PCB；
6. 选择端、使能端和未使用输入端不能随意悬空；
7. PCB 初版布局空间不足，需要重新规划器件和走线；
8. Multisim 工程为二进制文件，Git 无法自动合并电路冲突；
9. 方案修改后，README、技术方案和实现指南必须同步更新。
