# 4 位 ACC＋ALU 实物系统设计指南

> **最终方案：** 采用 74LS 系列器件、三位操作码和 PCB 实现。  
> **项目定位：** 本系统是累加器型数据通路，不是完整 CPU。

---

## 一、设计目标

本设计实现一个采用 `OP2 OP1 OP0` 三位操作码控制的 4 位 ACC＋ALU 运算系统。

系统能够完成 CLEAR、LOAD、ADD、SUB、AND、OR 六种基本功能，并通过 ACC 保存结果、参与下一次运算。

系统主要包括：

- 4 位 A 输入；
- 4 位 B 输入；
- 4 位 ALU；
- 三位操作码译码与控制；
- ACC 累加寄存器；
- A 输入与 ALU 结果选择；
- 手动时钟与按键消抖；
- LED 数据显示；
- Carry、Zero 状态显示。

---

## 二、最终系统结构

```text
A 输入 ───────────────┐
                      ├──→ 74LS157 → 74LS175 ACC → LED
ALU_RESULT ───────────┘                  │
                                         ▼
                                    4 位 ALU
                                    ▲      ▲
                                 ACC反馈   B输入

OP2 OP1 OP0 → 译码与控制 → MUX选择、ALU选择、ACC控制
CLK/EXEC    → 消抖整形   → ACC时钟
```

数据流说明：

1. LOAD 时，74LS157 选择 A 输入；
2. 运算时，74LS157 选择 ALU_RESULT；
3. ALU 的主要输入为 ACC 反馈和 B 输入；
4. 三位操作码决定 CLEAR、LOAD 或具体运算；
5. 按下 EXEC/CLK 后，ACC 在有效时钟沿保存所选结果；
6. ACC 输出显示在 LED 上，并反馈到下一次运算。

---

## 三、三位操作码定义

| OP2 | OP1 | OP0 | 功能 | 执行结果 |
|---:|---:|---:|---|---|
| 0 | 0 | 0 | CLEAR | `ACC ← 0000` |
| 0 | 0 | 1 | LOAD | `ACC ← A` |
| 0 | 1 | 0 | ADD | `ACC ← ACC + B` |
| 0 | 1 | 1 | SUB | `ACC ← ACC - B` |
| 1 | 0 | 0 | AND | `ACC ← ACC AND B` |
| 1 | 0 | 1 | OR | `ACC ← ACC OR B` |
| 1 | 1 | 0 | 保留 | 可用于 XOR 等扩展 |
| 1 | 1 | 1 | 保留 | 可用于其他扩展 |

操作码负责选择功能，时钟/执行按键负责将所选结果写入 ACC。

若最终原理图另设独立硬件复位按键，它作为辅助清零通路，不改变 `000 = CLEAR` 的功能定义。

---

## 四、主要功能

### 1. CLEAR：`000`

```text
ACC ← 0000
```

清零后，ACC LED 应显示 `0000`，Zero 应为 1。

### 2. LOAD：`001`

```text
ACC ← A
```

A 为外部 4 位初始数据输入。

### 3. ADD：`010`

```text
ACC ← ACC + B
```

### 4. SUB：`011`

```text
ACC ← ACC - B
```

### 5. AND：`100`

```text
ACC ← ACC & B
```

### 6. OR：`101`

```text
ACC ← ACC | B
```

## 五、主要器件

| 器件 | 主要作用 |
|---|---|
| 74LS175 | 4 位 ACC 数据保存 |
| 74LS157 | A 输入与 ALU_RESULT 选择 |
| 74LS14 | 按键消抖与脉冲整形 |
| 74LS07 | 缓冲与 LED 驱动 |
| 74LS 系列加法器和逻辑门 | ADD、SUB、AND、OR |
| 译码与门电路 | 三位操作码控制 |
| LED | 数据和状态显示 |
| 限流电阻 | LED 限流 |
| 轻触按键 | 手动时钟和辅助控制 |
| 拨码开关 | A、B 和 OP2～OP0 输入 |

### 逻辑系列说明

本项目最终采用 74LS 系列器件。普通 74HC 与 74LS 不应被描述为可以随意混用，因为 74LS 输出高电平不一定满足普通 74HC 的输入高电平门限。

需要 CMOS 器件且要求 TTL 输入门限时，应根据实际电平和器件手册考虑 74HCT 系列。

## 六、ALU 运算原理

### 1. ADD

```text
Y = ACC + B
```

Carry 取加法器最高位进位输出。

### 2. SUB

使用补码加法实现：

```text
ACC - B = ACC + (~B) + 1
```

典型控制逻辑：

```text
B'  = B XOR SUB
Cin = SUB
Y   = ACC + B' + Cin
```

当 `SUB=0` 时执行加法；当 `SUB=1` 时执行减法。

### 3. AND

```text
Y = ACC & B
```

### 4. OR

```text
Y = ACC | B
```

---

## 七、状态标志

### Carry

- ADD 时表示无符号加法进位；
- SUB 时为加法器最高位进位输出，其含义与普通加法进位不同；
- 如需显示 Borrow，应根据实际加法器 Cout 极性确定是否取反。

### Zero

```text
Zero = ~(ACC3 | ACC2 | ACC1 | ACC0)
```

当 ACC 当前值为 `0000` 时，Zero=1。

## 八、推荐测试顺序

### 1. 电源检查

- 检查 5V 与 GND；
- 检查每片芯片的 VCC、GND；
- 检查电源是否短路；
- 未使用输入端不得悬空。

### 2. 单独测试操作码

| 操作码 | 测试内容 | 预期 |
|---|---|---|
| `000` | CLEAR | ACC=0000 |
| `001` | A=0011，LOAD | ACC=0011 |
| `010` | ACC=0011，B=0010 | ACC=0101 |
| `011` | ACC=0101，B=0001 | ACC=0100 |
| `100` | ACC=1100，B=1010 | ACC=1000 |
| `101` | ACC=1000，B=0011 | ACC=1011 |

### 3. 单独测试 ACC

- LOAD 后 ACC 等于 A；
- 有效时钟沿到来后 ACC 更新；
- 无有效时钟沿时 ACC 保持；
- 一次按键只产生一次更新；
- CLEAR 后 ACC=0000。

### 4. 测试连续运算

```text
001：LOAD A=0011 → ACC=0011
010：ADD B=0010  → ACC=0101
010：ADD B=0001  → ACC=0110
011：SUB B=0010  → ACC=0100
```

确认 ACC 能保存中间结果并参与下一次运算。

### 5. 整机联调

```text
A / ALU_RESULT → MUX → ACC → ALU → ALU_RESULT → MUX
```

逐级测量各节点，不要一次性排查整机。

## 九、PCB 与实物注意事项

- 每片芯片电源附近建议配置去耦电容；
- LED 必须串联限流电阻；
- 选择端、使能端和未使用输入端不得悬空；
- 74LS07 为开集电极输出时，需要根据连接方式配置上拉；
- 机械按键不能直接作为可靠时钟，必须消抖和整形；
- 原理图修改后必须重新同步 PCB；
- 自建器件必须核对符号引脚号与封装焊盘号；
- OP2、OP1、OP0 的高低位顺序必须与 PCB 丝印和译码逻辑一致；
- 上电前使用万用表检查 5V 与 GND 是否短路。

## 十一、结论

本系统通过三位操作码、4 位 ALU、数据选择器、ACC 寄存器和手动时钟构成一个简化的累加器型数据通路。它能够展示功能译码、组合逻辑运算、寄存器写入和反馈运算的完整过程。
