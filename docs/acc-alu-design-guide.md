# 4 位 ACC＋ALU 实物系统设计指南

> **最终控制方式：** `OP2 OP1 OP0` 三位操作码。  
> **当前顶层数据通路：** 外部 B 用于 LOAD，外部 A 与 ACC 进入 ALU。  
> **减法方向：** `A - ACC`。  
> **项目定位：** 本系统是累加器型数据通路，不是完整 CPU。

---

## 一、设计目标

本设计实现一个采用三位操作码控制的 4 位 ACC＋ALU 运算系统。

系统能够完成 CLEAR、LOAD、ADD、SUB、AND、OR 六种基本功能，并通过 ACC 保存结果、参与下一次运算。

系统主要包括：

- 4 位外部 A 输入；
- 4 位外部 B 输入；
- 三位操作码译码；
- 4 位 ALU；
- ACC 累加寄存器；
- B 输入与 ALU_RESULT 选择；
- 手动时钟；
- ACC 四位 LED 显示；
- Carry 显示。

当前顶层未看到独立 Zero 输出，Zero 暂按可选扩展处理。

---

## 二、按当前原理图确定的数据通路

```text
外部 A ───────────────→ ALU A端 ───────────┐
ACC 输出 ─────────────→ ALU B端 ───────────┤
                                              ▼
                                          ALU_RESULT
                                              │
外部 B ───────────────┐                       │
                      ├──→ 74LS157 ───────────┘
ALU_RESULT ───────────┘
                              │
                              ▼
                         74LS175 ACC
                              │
                              ├──→ LED
                              └──→ 反馈到 ALU B端
```

由此可知：

- `LOAD` 时，ACC 装入外部 B；
- 运算时，ACC 装入 ALU_RESULT；
- ALU 的两个主要操作数为外部 A 与 ACC；
- ADD、AND、OR 的结果分别为 `A+ACC`、`A&ACC`、`A|ACC`；
- SUB 的结果为 `A-ACC`。

---

## 三、三位操作码定义

| OP2 | OP1 | OP0 | 功能 | 当前数据通路对应结果 |
|---:|---:|---:|---|---|
| 0 | 0 | 0 | CLEAR | `ACC ← 0000` |
| 0 | 0 | 1 | LOAD | `ACC ← B` |
| 0 | 1 | 0 | ADD | `ACC ← A + ACC` |
| 0 | 1 | 1 | SUB | `ACC ← A - ACC` |
| 1 | 0 | 0 | AND | `ACC ← A AND ACC` |
| 1 | 0 | 1 | OR | `ACC ← A OR ACC` |
| 1 | 1 | 0 | 保留 | 当前行为未定义 |
| 1 | 1 | 1 | 保留 | 当前行为未定义 |

操作码负责选择功能，时钟按键负责更新 ACC。

### SUB 方向确认

ALU 内部连接为：

```text
A 端直接进入 74LS283
ACC 端先与 SUB_EN 异或后进入 74LS283 的 B 端
SUB_EN 同时接入最低位进位 Cin
```

因此，当 `SUB_EN=1` 时：

```text
SUM = A + (~ACC) + 1 = A - ACC
```

## 四、译码与有效电平

当前译码模块使用三线—八线译码器：

```text
OP2 OP1 OP0 → 74HC138/同功能器件
```

输出关系：

- `Y0` 直接作为低有效 `CLEAR_N`；
- `Y1` 反相后生成高有效 `LOAD`；
- `Y2` 反相后生成高有效 `ADD_EN`；
- `Y3` 反相后生成高有效 `SUB_EN`；
- `Y4` 反相后生成高有效 `AND_EN`；
- `Y5` 反相后生成高有效 `OR_EN`；
- `Y6`、`Y7` 对应保留操作码。

仿真截图使用 74HC138、74HC04 模型；实际 PCB/BOM 若采用 74LS138、74LS04，应明确区分仿真模型和实物型号。

## 五、当前必须检查的硬件问题

### 1. 74LS253 输出使能端

从 ALU 截图看，U26、U27 的低有效输出使能端：

```text
/1G
/2G
```

看起来没有连接。

74LS253 的 `/1G`、`/2G` 必须为低电平时输出才有效，因此应明确接到 GND。不能依靠悬空输入。

### 2. 74LS74 异步端

U4A 的低有效异步端：

```text
/PRE
/CLR
```

从截图看也像是未连接。

若不使用异步置位和清零，应把 `/PRE`、`/CLR` 接到 VCC。若希望系统清零时同步清除 Carry，可将 `/CLR` 接入合适的低有效清零信号，但必须避免 `/PRE` 与 `/CLR` 同时有效。

### 3. 保留操作码 `110`、`111`

当 `AND_EN=0`、`OR_EN=0`、`SUB_EN=0` 时，74LS253 会选择 SUM 通路，74LS283 计算 `A+ACC`。

因此，若 `110` 或 `111` 时仍允许时钟写入 ACC，它们很可能并不是 HOLD，而会接近“无 Carry 显示的 ADD”。

最终硬件至少应采用一种保护方式：

1. 保留码时屏蔽 ACC 时钟；
2. 保留码时强制 `ACC_next=ACC`；
3. 明确规定 `110`、`111` 禁止按时钟。

最推荐：

```text
OP=110 或 111：ACC_next = ACC
```

### 4. Carry 的有效范围

74LS283 的 Cout 经过 `ADD_EN` 与门后才进入 Carry 通路，因此当前 Carry 只在 ADD 时有效。

SUB 时没有独立 Borrow 输出。文档和答辩中不要把当前 Carry 描述为减法借位。

## 六、状态显示

### Carry

当前顶层具有 Carry 输出，但只在 ADD 时有效。

### Zero

当前顶层截图未看到独立 Zero 输出。

因此文档应写成：

```text
Zero：可选扩展，当前顶层未实现或待确认。
```

需要补充时，可使用：

```text
Zero = ~(ACC3 | ACC2 | ACC1 | ACC0)
```

## 七、主要器件

| 器件 | 主要作用 |
|---|---|
| 74LS175 | 4 位 ACC 数据保存 |
| 74LS157 | 外部 B 与 ALU_RESULT 选择 |
| 74LS14 | 实物按键消抖与整形 |
| 74LS07 | 缓冲与 LED 驱动 |
| 74LS138 / 同功能译码器 | 三位操作码译码 |
| 74LS04 / 同功能反相器 | 将低有效译码输出转换为高有效使能 |
| 74LS253 | ALU 结果选择 |
| 74LS74 | Carry 状态保存 |
| 74LS283 | 4 位加减法 |
| 74LS86 | SUB 时对 ACC 按位取反 |
| 74LS08、74LS32 | AND、OR 运算 |
| LED、限流电阻 | 数据和状态显示 |
| 拨码开关 | A、B 和 OP2～OP0 输入 |
| 轻触按键 | 手动时钟 |

普通 74HC 与 74LS 不应被描述为可以随意混用。器件替换必须核对输入门限、输出电平和驱动能力。

## 八、推荐测试顺序

### 1. CLEAR

```text
OP=000
预期：ACC=0000
```

### 2. LOAD

```text
B=0011
OP=001
按一次时钟
预期：ACC=0011
```

### 3. ADD

```text
先 LOAD：ACC=0011
A=0010
OP=010
按一次时钟
预期：ACC=0101
```

### 4. SUB

```text
先 LOAD：ACC=0011
A=0101
OP=011
按一次时钟
预期：ACC=0010
```

因为当前减法为：

```text
A - ACC = 0101 - 0011 = 0010
```

### 5. AND

```text
先 LOAD：ACC=1010
A=1100
OP=100
预期：ACC=1000
```

### 6. OR

```text
先 LOAD：ACC=1000
A=0011
OP=101
预期：ACC=1011
```

### 7. 保留码

分别测试 `110` 和 `111`：

- 不按时钟时 ACC 应保持；
- 按时钟后不得意外执行 ADD；
- 最终版本建议实现 HOLD。

## 九、PCB 与实物注意事项

- OP0 应接译码器最低位输入，OP2 应接最高位输入；
- 译码器使能端必须连接为有效状态；
- `CLEAR_N` 是低有效信号；
- 74LS253 的 `/1G`、`/2G` 必须接 GND；
- 74LS74 未使用的 `/PRE`、`/CLR` 必须接确定电平；
- 机械按键作为时钟时需要消抖；
- LED 必须串联限流电阻；
- 74LS07 为开集电极输出时需要检查上拉；
- 未使用输入不得悬空；
- 每片芯片电源附近建议配置去耦电容；
- 上电前检查 5V 与 GND 是否短路。
