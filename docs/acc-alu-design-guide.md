# 4 位 ALU-Accumulator 运算器设计指南

> 原题：自拟题目方案——4 位 ALU-Accumulator 运算器设计  
> 适用场景：数字电路课程设计、Multisim 仿真、面包板或 PCB 实物实现

---

## 一、题目名称

推荐题目：

> 基于 Multisim 与面包板的 4 位 ALU-Accumulator 运算器设计

也可以写得更课程化：

> 基于中规模集成芯片的 4 位可编程算术逻辑运算器设计

---

## 二、设计目标

本设计实现一个简单的 4 位数据通路系统，能够完成基本算术逻辑运算，并通过累加器保存运算结果。

系统主要由以下模块组成：

- 4 位输入模块；
- 4 位 ALU 运算模块；
- 累加器 ACC；
- 操作选择模块；
- 控制逻辑模块；
- 标志位模块；
- LED 显示模块。

设计重点不是做完整 CPU，而是实现一个处理器数据通路中的基础运算单元。

---

## 三、功能要求

### 1. 基础版：必须完成

| 功能 | 要求 |
|---|---|
| 输入 | 4 位 A 输入、4 位 B 输入，可由拨码开关设置 |
| 运算 | 支持 ADD、SUB、AND、OR 四种运算 |
| 输出 | 4 位 LED 显示运算结果 |
| 标志位 | Carry 标志、Zero 标志 |
| 累加器 | 可将运算结果锁存到 ACC |
| 控制 | 支持 LOAD / EXEC / CLEAR 基本控制 |
| 仿真 | 在 Multisim 中完成完整仿真 |
| 实物 | 用面包板和 DIP 直插芯片实现基础功能 |

基础版已经足够作为课程设计主体。

### 2. 扩展版：时间充足时再做

扩展功能不要一开始承诺太多，建议写成“可扩展功能”。

| 扩展功能 | 推荐程度 | 说明 |
|---|---:|---|
| XOR 运算 | 高 | 增加一片 74HC86 即可，较容易 |
| Overflow 标志 | 中 | 可用于补码加减法溢出判断 |
| SHL / SHR 移位 | 中 | 会增加选择器和接线复杂度 |
| 状态 LED | 高 | 显示当前 LOAD / EXEC / CLEAR 状态 |
| 七段数码管显示 | 低 | 接线复杂，不如 LED 二进制显示稳定 |

建议最终承诺：

> 基础完成 ADD、SUB、AND、OR、ACC、Carry、Zero；若时间允许，再扩展 XOR 和 Overflow。

控制信号：

- `CLEAR`：清零。

## 五、推荐的运算定义

建议使用 2 位操作码选择 4 种运算：

| OP1 | OP0 | 运算 | 说明 |
|---:|---:|---|---|
| 0 | 0 | ADD | A + B |
| 0 | 1 | SUB | A - B |
| 1 | 0 | AND | A & B |
| 1 | 1 | OR | A \| B |

加入 ACC 后，可以采用两种设计路线。

### 路线一：简单版 ALU

```text
结果 = A op B
ACC ← A op B
```

ACC 只负责保存结果。

**优点：**

- 结构简单；
- 便于仿真；
- 便于面包板实现；
- 老师容易理解。

**缺点：**

- 累加器特征稍弱。

### 路线二：累加器型数据通路

```text
结果 = ACC op B
```

其中：

- ACC 保存当前数据；
- B 是外部输入；
- 每次 EXEC 后更新 ACC。

例如：

```text
ACC ← ACC + B
ACC ← ACC - B
ACC ← ACC & B
ACC ← ACC | B
```

这种结构更像简单的累加器型处理器。

**优点：**

- 更贴近处理器数据通路；
- 答辩时更好讲；
- 可以演示连续累加、连续减法。

**缺点：**

- 初始装载 ACC 需要设计 LOAD 功能。

建议最终采用路线二，但应在报告中说明它是“累加器型数据通路”，不是完整 CPU。

## 六、推荐最终功能流程

建议定义三个主要操作。

### 1. CLEAR

清零 ACC：

```text
ACC ← 0000
```

LED 显示 `0000`。

### 2. LOAD

把拨码开关输入的 4 位数据装入 ACC：

```text
ACC ← A
```

其中 A 是初值输入。

### 3. EXEC

选择一种运算，将 ACC 与 B 运算，然后把结果写回 ACC：

```text
ACC ← ACC op B
```

示例：

| 当前 ACC | B 输入 | OP | 执行后 ACC |
|---|---|---|---|
| 0011 | 0010 | ADD | 0101 |
| 0101 | 0001 | SUB | 0100 |
| 1100 | 1010 | AND | 1000 |
| 1000 | 0011 | OR | 1011 |

现场可以先 LOAD 一个数，再连续 EXEC 几次，以说明 ACC 会保存中间结果。

## 七、核心模块设计

### 模块 1：输入模块

使用：

- 4 位拨码开关作为 A；
- 4 位拨码开关作为 B；
- 2 位拨码开关作为 OP；
- 按键作为 LOAD、EXEC、CLEAR。

每个拨码开关最好配置上拉或下拉电阻，避免输入悬空。

### 模块 2：算术模块

ADD 和 SUB 可以共用一片 4 位加法器。

推荐逻辑：

```text
SUB = 0 时：ACC + B
SUB = 1 时：ACC + (~B) + 1
```

即使用补码实现减法。

需要：

- 74HC283：4 位二进制加法器；
- 74HC86：异或门，用于 B 与 SUB 异或；
- SUB 信号连接加法器 `Cin`。

逻辑为：

```text
B'  = B XOR SUB
Cin = SUB
Sum = ACC + B' + Cin
```

当 `SUB = 0`：

```text
Sum = ACC + B
```

当 `SUB = 1`：

```text
Sum = ACC + ~B + 1 = ACC - B
```

这部分是整个设计中最值得讲解的内容。

### 模块 3：逻辑运算模块

需要实现：

```text
ACC AND B
ACC OR B
```

可以使用：

- 74HC08：四路 AND；
- 74HC32：四路 OR。

如果扩展 XOR：

- 74HC86：四路 XOR。

### 模块 4：结果选择模块

ALU 同时产生多个结果：

- ADD/SUB 结果；
- AND 结果；
- OR 结果。

然后根据 `OP1`、`OP0` 选择最终结果。

可以使用：

- 74HC153：双 4 选 1 数据选择器；
- 或使用多个 74HC157 二选一选择器组合实现。

推荐使用 74HC153，因为它更适合实现 4 选 1。

4 位结果需要分别选择 4 路，通常需要：

- 2 片 74HC153。

一片 74HC153 内含两个 4 选 1，多用两片可以完成 4 位选择。

### 模块 5：ACC 累加器

ACC 用于保存 4 位结果。

可选芯片：

- 74HC173；
- 74HC175；
- 74HC273；
- 74HC374。

推荐使用：

> 74HC173 或 74HC175

如果买不到，74HC273 / 74HC374 也可以，但清零和使能方式要根据具体芯片功能确定。

ACC 的功能：

```text
LOAD 时：  ACC ← A
EXEC 时：  ACC ← ALU_RESULT
CLEAR 时： ACC ← 0000
```

要实现该功能，需要在 ACC 输入前设置数据选择：

```text
ACC 输入 = A 或 ALU_RESULT
```

可以使用 74HC157 实现 4 位二选一。

| 控制状态 | ACC 输入 |
|---|---|
| LOAD | A |
| EXEC | ALU_RESULT |

CLEAR 可以使用寄存器清零端，也可以通过输入 `0000` 后写入实现。

### 模块 6：标志位模块

建议基础版实现两个标志。

#### Carry 标志

直接取 74HC283 的 `Cout`。

注意：

- ADD 时，Carry 表示进位；
- SUB 时，Carry 与借位的关系需要解释清楚。

答辩时可表述为：

> 本设计中 Carry 标志主要用于无符号加法进位显示；减法时作为加法器最高位进位输出观察。

#### Zero 标志

Zero 表示结果是否为 `0000`。

逻辑表达式：

```text
Zero = ~(Y3 | Y2 | Y1 | Y0)
```

可以使用：

- 74HC32 实现 OR；
- 74HC04 实现 NOT；
- 或使用 74HC02 NOR 门实现。

当 `Zero = 1` 时，点亮 Zero LED。

### 模块 7：控制模块

为了降低风险，控制部分不要设计复杂 FSM，可采用“手动控制 + 简单状态指示”。

#### 基础控制方式

| 按键 | 功能 |
|---|---|
| CLEAR | 清零 ACC |
| LOAD | 将 A 装入 ACC |
| EXEC | 执行 ACC op B，并写回 ACC |

这种方式最适合面包板。它仍然具备控制逻辑，但不会把项目拖入复杂 CPU 控制器。

#### 扩展控制方式

若需要增加 FSM 特征，可以定义 3 个状态：

| 状态 | 含义 | 输出控制 |
|---|---|---|
| S0 | IDLE | 等待操作 |
| S1 | LOAD | 装载 A 到 ACC |
| S2 | EXEC | 执行运算并写回 ACC |

建议在报告中画 FSM，实物上仍使用按键直接产生控制信号，风险更低。

建议按以下顺序搭建，不要一开始就搭完整电路。

先只搭：

- ACC 输入；
- B 输入；
- 74HC86；
- 74HC283；
- SUB 控制；
- Sum 输出 LED；

测试：

| ACC | B | AND | OR |

| 1100 | 1010 | 1000 | 1110 |
| 0101 | 0011 | 0001 | 0111 |

## 十、面包板搭建顺序

实物千万不要一次性全部接好，应分模块逐步搭建。

### 1. 电源检查

先只连接：

- 5V；
- GND；
- 每片芯片的 VCC、GND；
- 电源指示 LED。

确认没有短路。

### 2. 单独测试 74HC283

先不使用 ACC，直接用拨码开关输入 A、B，确认加法正确。

### 3. 加入 74HC86，实现 SUB

测试减法是否正确。

### 4. 加入 AND / OR

单独观察逻辑输出是否正确。

### 5. 加入 MUX

确认 OP 选择结果没有错误。

### 6. 加入 ACC

这是最容易出现问题的模块，应先单独测试：

```text
A → ACC → LED
```

确认 LOAD 和 CLEAR 正常后，再连接 ALU。

### 7. 最后联调

最终实现：

```text
ACC → ALU → MUX → ACC
```

只要前面每个模块都单独测试过，联调难度会显著降低。

## 十五、老师可能问的问题

### 问题 1：这个是不是 CPU？

**回答：**

不是。本设计只实现了处理器数据通路中的一个基础运算单元，包括 ALU、累加器和简单控制逻辑，没有指令存储器、程序计数器、译码器等完整 CPU 结构。

### 问题 2：为什么减法可以用加法器实现？

**回答：**

因为二进制补码中，`A - B` 可以转换为 `A + ~B + 1`。本设计用异或门控制 B 是否取反，同时将 SUB 信号接入加法器的 `Cin`，实现加减法共用同一个 4 位加法器。

### 问题 3：ACC 的作用是什么？

**回答：**

ACC 是累加器，用于保存当前运算结果。下一次运算时，ACC 可以作为 ALU 的一个输入，从而实现连续运算。这种结构类似早期累加器型处理器的数据通路。

### 问题 4：Zero 标志怎么产生？

**回答：**

当 4 位输出全部为 0 时，Zero 标志为 1：

```text
Zero = ~(Y3 | Y2 | Y1 | Y0)
```

### 问题 5：为什么不用数码管显示？

**回答：**

本设计重点是数据通路和运算逻辑。二进制 LED 显示能够直观反映每一位结果，也能减少译码和扫描电路带来的接线复杂度，使实物调试更可靠。

## 十六、风险控制建议

该题目的主要风险包括：

1. 面包板接线太多；
2. 按键抖动；
3. ACC 写入时序不稳定；
4. MUX 选择线接错；
5. 74HC 芯片输入悬空导致异常。

对应措施：

| 风险 | 解决办法 |
|---|---|
| 接线复杂 | 分模块搭建，逐步联调 |
| 按键抖动 | 加 RC 消抖或 74HC14 |
| 输入悬空 | 所有输入加上拉或下拉 |
| ACC 写入异常 | 先单独测试寄存器，再连接 ALU |
| 输出错误 | 每个模块先用 LED 单独测试 |

## 十七、最终建议版本

与老师沟通时，不建议一开始说“想做处理器数据通路”，可以这样表述：

> 老师，我们想自拟一个和中规模数字芯片设计相关的题目，做一个 4 位 ALU-Accumulator 运算器。功能包括 4 位加法、减法、与、或运算，用累加器保存结果，并用 LED 显示结果和进位、零标志。仿真使用 Multisim，实物使用 74HC 系列 DIP 芯片和面包板实现。规模大致与数字秒表、定时开关、序列检测器类似。

### 一句话版本

> 推荐形态为：4 位 ALU + ACC + 手动 LOAD / EXEC / CLEAR 控制；基础实现 ADD、SUB、AND、OR、Carry、Zero，扩展再考虑 XOR、Overflow 或简单 FSM。
