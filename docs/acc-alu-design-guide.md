# 4 位 ACC＋ALU 实物系统设计指南

> **最终方案：** 采用 74LS 系列器件和 PCB 实现；使用 2 位运算选择、反馈选择、手动时钟和清零控制。  
> **项目定位：** 本系统是累加器型数据通路，不是完整 CPU。

---

## 一、设计目标

本设计实现一个 4 位 ACC＋ALU 运算系统，能够完成基本算术逻辑运算，并通过 ACC 保存结果、参与下一次运算。

系统主要包括：

- 4 位外部数据输入；
- 4 位 ALU；
- ACC 累加寄存器；
- 外部输入与 ACC 反馈选择；
- 手动时钟与按键消抖；
- LED 数据显示；
- Carry、Zero 等状态显示。

---

## 二、最终系统结构

```text
外部 B 输入 ──┐
              ├──→ 74LS157 → 4 位 ALU → 74LS175 ACC → LED
ACC 反馈 ─────┘                              │
                                             └──反馈到下一次运算
```

数据流说明：

1. 74LS157 选择外部数据或 ACC 反馈数据；
2. ALU 根据 `OP1 OP0` 完成运算；
3. 按下 EXEC/CLK 按键；
4. 74LS14 对按键信号进行消抖和整形；
5. 有效时钟沿到来后，74LS175 保存 ALU 输出；
6. ACC 输出显示在 LED 上，并反馈到下一次运算。

---

## 三、最终控制定义

| 控制信号 | 功能 |
|---|---|
| `OP1 OP0` | 选择 ADD、SUB、AND、OR |
| `INPUT_SEL` | 选择外部输入或 ACC 反馈 |
| `EXEC / CLK` | 将 ALU 结果锁存到 ACC |
| `CLEAR` | 清零 ACC |

### 运算选择

| OP1 | OP0 | 运算 | 说明 |
|---:|---:|---|---|
| 0 | 0 | ADD | 两个 4 位数据相加 |
| 0 | 1 | SUB | 两个 4 位数据相减 |
| 1 | 0 | AND | 按位与 |
| 1 | 1 | OR | 按位或 |

> 最终方案不使用“3 位操作码同时编码 CLEAR、LOAD 和四种运算”的方式。CLEAR、输入选择和时钟均使用独立控制信号，避免控制含义重复。

---

## 四、主要功能

### 1. CLEAR

```text
ACC ← 0000
```

清零后，ACC LED 应显示 `0000`。

### 2. 外部输入装载

将 `INPUT_SEL` 切换到外部输入通路，设置外部 4 位数据和所需运算条件，再通过有效时钟沿更新 ACC。

### 3. 反馈运算

将 `INPUT_SEL` 切换到 ACC 反馈通路后，ACC 保存的数据可继续参与下一次运算，实现连续累加、连续减法和多步逻辑运算。

---

## 五、主要器件

| 器件 | 主要作用 |
|---|---|
| 74LS175 | 4 位 ACC 数据保存 |
| 74LS157 | 外部输入与 ACC 反馈选择 |
| 74LS14 | 按键消抖与脉冲整形 |
| 74LS07 | 缓冲与 LED 驱动 |
| 74LS 系列加法器和逻辑门 | ADD、SUB、AND、OR |
| LED | 数据和状态显示 |
| 限流电阻 | LED 限流 |
| 轻触按键 | 手动时钟和清零控制 |
| 拨码开关 | 数据与运算选择输入 |

### 逻辑系列说明

本项目最终采用 74LS 系列器件。普通 74HC 与 74LS 不应在文档中描述为可以随意混用，因为 74LS 输出高电平不一定满足普通 74HC 的输入高电平门限。

需要 CMOS 器件且要求 TTL 输入门限时，应根据实际电平和器件手册考虑 74HCT 系列。

## 六、ALU 运算原理

### 1. ADD

```text
Y = A + B
```

Carry 取加法器最高位进位输出。

### 2. SUB

使用补码加法实现：

```text
A - B = A + (~B) + 1
```

典型控制逻辑：

```text
B'  = B XOR SUB
Cin = SUB
Y   = A + B' + Cin
```

当 `SUB=0` 时执行加法；当 `SUB=1` 时执行减法。

### 3. AND

```text
Y = A & B
```

### 4. OR

```text
Y = A | B
```

---

## 七、状态标志

### Carry

- ADD 时表示无符号加法进位；
- SUB 时为加法器最高位进位输出，其含义与普通加法进位不同；
- 如需显示 Borrow，应根据实际加法器 Cout 极性确定是否取反。

### Zero

```text
Zero = ~(Y3 | Y2 | Y1 | Y0)
```

当结果为 `0000` 时，Zero=1。

## 八、推荐测试顺序

### 1. 电源检查

- 检查 5V 与 GND；
- 检查每片芯片的 VCC、GND；
- 检查电源是否短路；
- 未使用输入端不得悬空。

### 2. 单独测试 ALU

| A | B | 运算 | 预期结果 |
|---|---|---|---|
| 0011 | 0010 | ADD | 0101 |
| 0101 | 0011 | SUB | 0010 |
| 1100 | 1010 | AND | 1000 |
| 0101 | 0011 | OR | 0111 |
| 1111 | 0001 | ADD | 0000，Carry=1 |

### 3. 单独测试 ACC

- CLEAR 后 ACC=0000；
- 有效时钟沿到来后 ACC 更新；
- 无有效时钟沿时 ACC 保持；
- 连续按键一次只产生一次更新。

### 4. 测试反馈通路

示例：

```text
初始 ACC = 0011
外部 B   = 0010
ADD 后   = 0101
再次 ADD = 0111
```

确认 ACC 能保存中间结果并参与下一次运算。

### 5. 整机联调

```text
外部输入 / ACC反馈 → MUX → ALU → ACC → LED
```

逐级测量各节点，不要一次性排查整机。

---

## 九、PCB 与实物注意事项

- 每片芯片电源附近建议配置去耦电容；
- LED 必须串联限流电阻；
- 选择端、使能端和未使用输入端不得悬空；
- 74LS07 为开集电极输出时，需要根据连接方式配置上拉；
- 机械按键不能直接作为可靠时钟，必须消抖和整形；
- 原理图修改后必须重新同步 PCB；
- 自建器件必须核对符号引脚号与封装焊盘号；
- 上电前使用万用表检查 5V 与 GND 是否短路。

## 十一、结论

本系统通过 4 位 ALU、数据选择器、ACC 寄存器和手动时钟构成一个简化的累加器型数据通路。它能够展示组合逻辑结果如何在时钟控制下写入寄存器，并在后续运算中继续使用，是数字电路课程设计中组合逻辑与时序逻辑结合的完整实例。
