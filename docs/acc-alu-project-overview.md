# 基于三位操作码控制的 4 位 ACC＋ALU 项目简介

## 一、项目概述

本项目设计并实现一个采用 `OP2 OP1 OP0` 三位操作码控制的 4 位 ACC＋ALU 运算系统。

系统能够完成 CLEAR、LOAD、ADD、SUB、AND、OR 六种基本功能，并使用 ACC 累加寄存器保存结果。ACC 中的数据可以参与下一次运算，从而实现连续累加、连续减法和多步逻辑运算。

本项目不是完整 CPU，不包含程序计数器、指令 ROM 和完整取指—译码—执行流程。设计重点是展示组合逻辑、寄存器、操作码译码和时钟控制之间的配合。

---

## 二、系统组成

- 4 位 A 输入；
- 4 位 B 输入；
- 3 位操作码输入 OP2～OP0；
- 4 位 ALU；
- 74LS157 数据选择器；
- 74LS175 ACC 寄存器；
- 74LS14 按键消抖与整形；
- 74LS07 缓冲与 LED 驱动；
- Carry、Zero 状态显示；
- 手动执行时钟。

```text
A 输入 ───────────────┐
                      ├──→ 数据选择 → ACC → LED
ALU_RESULT ───────────┘              │
                                     ▼
                                    ALU
                                  ▲     ▲
                               ACC反馈  B输入

OP2 OP1 OP0 → 译码与控制
CLK/EXEC    → ACC时钟
```

## 三、三位操作码

| OP2 | OP1 | OP0 | 功能 | 执行结果 |
|---:|---:|---:|---|---|
| 0 | 0 | 0 | CLEAR | `ACC ← 0000` |
| 0 | 0 | 1 | LOAD | `ACC ← A` |
| 0 | 1 | 0 | ADD | `ACC ← ACC + B` |
| 0 | 1 | 1 | SUB | `ACC ← ACC - B` |
| 1 | 0 | 0 | AND | `ACC ← ACC AND B` |
| 1 | 0 | 1 | OR | `ACC ← ACC OR B` |
| 1 | 1 | 0 | 保留 | 后续扩展 |
| 1 | 1 | 1 | 保留 | 后续扩展 |

操作码决定当前功能，执行按键或时钟边沿负责将所选结果写入 ACC。

若实物保留独立复位按键，它作为辅助硬件复位，不改变 `000 = CLEAR` 的功能定义。

---

## 四、基本工作过程

```text
1. 设置 OP=000，执行 CLEAR；
2. 设置 A 和 OP=001，执行 LOAD；
3. 设置 B 和运算操作码；
4. 按下 EXEC/CLK；
5. ACC 保存运算结果；
6. 修改 B 或操作码后继续运算。
```

示例：

```text
OP=000：CLEAR        → ACC=0000
A=0011，OP=001：LOAD → ACC=0011
B=0010，OP=010：ADD  → ACC=0101
B=0001，OP=011：SUB  → ACC=0100
```

## 六、器件与实现方式

本项目最终采用 74LS 系列 DIP 直插器件和 PCB 实现。

| 器件 | 作用 |
|---|---|
| 74LS175 | ACC 寄存器 |
| 74LS157 | A 输入与 ALU_RESULT 选择 |
| 74LS14 | 按键消抖和整形 |
| 74LS07 | 缓冲与 LED 驱动 |
| 74LS 系列逻辑器件 | ALU、译码和控制 |
| LED、电阻、按键、拨码开关 | 输入与显示 |

> 普通 74HC 与 74LS 不应被描述为可以随意混用。器件替换必须核对电源电压、输入门限、输出电平和驱动能力。
