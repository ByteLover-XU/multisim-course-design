# 基于操作码控制的 4 位 ALU-Accumulator 运算器项目简介

## 一、项目概述

本项目设计并实现一个**基于操作码控制的 4 位 ALU-Accumulator 运算器**。

系统能够接收两个 4 位二进制数据，并根据操作码完成加法、减法、逻辑与、逻辑或等运算。运算结果可以保存到累加器 ACC 中，供后续连续运算使用。

可以把整个系统理解为一个小型“数字计算工厂”：

- **ALU**：负责完成加、减、与、或等运算；
- **ACC（Accumulator）**：保存当前或上一次运算结果；
- **操作码控制模块**：根据拨码开关输入的操作码选择具体功能；
- **LED 显示模块**：显示 ACC 结果、Carry 和 Zero 状态。

本项目**不实现完整 CPU**，不包含程序计数器、指令存储器和完整取指—译码—执行流程。设计重点是实现一个规模适中的运算处理单元，体现组合逻辑与时序逻辑的结合。

---

## 二、基础功能

基础版是项目主体，应优先完成并保证稳定运行。

### 1. 数据输入

- 4 位数据输入 A；
- 4 位数据输入 B；
- A、B 均由拨码开关设置。

### 2. 操作码输入

系统使用 3 位操作码选择功能。

| 操作码 | 功能 | 执行结果 |
|---|---|---|
| `000` | CLEAR | `ACC ← 0000` |
| `001` | LOAD | `ACC ← A` |
| `010` | ADD | `ACC ← ACC + B` |
| `011` | SUB | `ACC ← ACC - B` |
| `100` | AND | `ACC ← ACC AND B` |
| `101` | OR | `ACC ← ACC OR B` |
| `110` | 保留 | 可用于后续扩展 |
| `111` | 保留 | 可用于后续扩展 |

### 3. 控制方式

系统使用按键产生基本控制信号：

- **CLEAR**：清零 ACC；
- **LOAD**：将 A 输入装入 ACC；
- **EXEC**：执行当前操作码对应的运算，并将结果写回 ACC。

### 4. 输出显示

- 4 个 LED 显示 ACC 的 4 位结果；
- Carry LED 显示进位状态；
- Zero LED 显示结果是否为 `0000`。

### 5. 实现工具

- 首先在 **NI Multisim** 中完成电路仿真；
- 再使用 74HC 或 74LS 系列 DIP 直插芯片完成实物搭建；
- 实物部分可使用面包板，也可进一步制作 PCB。

---

## 三、系统工作过程

推荐的基本操作流程如下：

```text
CLEAR → LOAD → EXEC → EXEC → …
```

示例：

```text
1. CLEAR：ACC ← 0000
2. 设置 A = 0011
3. LOAD：ACC ← 0011
4. 设置 B = 0010，操作码选择 ADD
5. EXEC：ACC ← 0011 + 0010 = 0101
6. 修改 B 或操作码后继续 EXEC
```

通过连续执行，可以观察 ACC 保存中间结果，并参与下一次运算。

## 四、扩展功能

基础功能稳定后，可以根据时间和实现难度增加以下功能：

### 1. 操作码译码

加入译码器芯片，根据 3 位操作码自动产生：

- CLEAR；
- LOAD；
- ADD；
- SUB；
- AND；
- OR；

等控制信号。

### 2. 简单状态机

可以设计简单 FSM，使系统按以下状态运行：

```text
IDLE → LOAD → EXEC → DISPLAY
```

同时使用 LED 显示当前状态。

### 3. 其他可选扩展

- XOR 异或运算；
- Overflow 溢出标志；
- 状态 LED；
- 更完整的按键消抖；
- 自动时钟或单步时钟；
- PCB 实物实现。

> 扩展功能应在基础版完全稳定后再加入，避免电路规模过大、接线混乱和调试困难。

## 五、项目意义

本项目可以综合运用数字电路课程中的以下知识：

- 二进制加法器；
- 补码减法；
- 与门、或门、异或门；
- 数据选择器；
- 译码器；
- D 触发器和寄存器；
- 时钟与按键消抖；
- LED 显示；
- 组合逻辑与时序逻辑的配合。

ALU 和 ACC 都是真实处理器数据通路中的重要组成部分。通过该项目，可以直观理解运算结果如何产生、保存并参与下一次运算。
