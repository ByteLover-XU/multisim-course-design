# 4 位 ACC＋ALU 实物系统项目简介

## 一、项目概述

本项目设计并实现一个 4 位 ACC＋ALU 运算系统。

系统能够完成加法、减法、逻辑与、逻辑或等运算，并使用 ACC 累加寄存器保存结果。ACC 保存的数据能够反馈到后续运算通路，从而实现连续累加、连续减法和多步逻辑运算。

本项目不是完整 CPU，不包含程序计数器、指令 ROM 和完整取指—译码—执行流程。设计重点是展示组合逻辑、寄存器、数据选择和时钟控制之间的配合。

---

## 二、系统组成

系统主要包括：

- 4 位外部数据输入；
- 4 位 ALU；
- 74LS157 数据选择器；
- 74LS175 ACC 寄存器；
- 74LS14 按键消抖与整形；
- 74LS07 缓冲与 LED 驱动；
- Carry、Zero 状态显示；
- 手动时钟和清零控制。

```text
外部 B 输入 ──┐
              ├──→ 数据选择 → ALU → ACC → LED
ACC 反馈 ─────┘                    │
                                   └──反馈到下一次运算
```

---

## 三、最终控制方式

系统使用独立控制信号，不采用“3 位操作码同时编码 CLEAR、LOAD 和运算”的方案。

| 控制信号 | 功能 |
|---|---|
| `OP1 OP0` | 选择 ADD、SUB、AND、OR |
| `INPUT_SEL` | 选择外部数据或 ACC 反馈 |
| `EXEC / CLK` | 产生有效时钟沿，将结果写入 ACC |
| `CLEAR` | 清零 ACC |

### 运算选择表

| OP1 | OP0 | 运算 |
|---:|---:|---|
| 0 | 0 | ADD |
| 0 | 1 | SUB |
| 1 | 0 | AND |
| 1 | 1 | OR |

---

## 四、基本工作过程

```text
1. CLEAR：清零 ACC；
2. 设置外部数据和 OP1、OP0；
3. 设置 INPUT_SEL，选择外部输入或 ACC 反馈；
4. ALU 产生组合逻辑结果；
5. 按下 EXEC/CLK；
6. ACC 在有效时钟沿保存结果；
7. 修改输入或运算类型后继续执行。
```

示例：

```text
初始 ACC = 0011
外部输入 = 0010
OP = ADD
EXEC 后 ACC = 0101

继续使用反馈结果：
ACC = 0101
外部输入 = 0001
OP = SUB
EXEC 后 ACC = 0100
```

## 六、器件与实现方式

本项目最终采用 74LS 系列 DIP 直插器件和 PCB 实现。

| 器件 | 作用 |
|---|---|
| 74LS175 | ACC 寄存器 |
| 74LS157 | 输入与反馈选择 |
| 74LS14 | 按键消抖和整形 |
| 74LS07 | 缓冲与 LED 驱动 |
| 74LS 系列逻辑器件 | ALU 运算与控制 |
| LED、电阻、按键、拨码开关 | 人机输入与显示 |

> 普通 74HC 与 74LS 不应被描述为可以随意混用。器件替换必须核对电源电压、输入门限、输出电平和驱动能力。

## 七、项目意义

本项目综合使用了：

- 二进制加法与补码减法；
- 与、或等组合逻辑；
- 数据选择器；
- D 触发器和寄存器；
- 时钟与按键消抖；
- LED 显示与驱动；
- 原理图、PCB 和实物调试。

通过本项目可以直观理解：

```text
组合逻辑产生结果
        ↓
时钟沿将结果写入寄存器
        ↓
寄存器结果参与下一次运算
```
